# Google Play release notes — v0.11.0

## English (United States)

```text
KoalaCast 0.11.0 adds privacy-first explicit-content controls, HTTPS-only server connections in release builds, and the option to delete synchronized listening data while keeping your account. It also strengthens playback filtering, release checks, account-deletion safety, and Android 16 compatibility.
```

## German (Germany)

```text
KoalaCast 0.11.0 ergänzt datenschutzfreundliche Filter für explizite Inhalte, ausschließlich HTTPS-Server in Release-Builds und das Löschen synchronisierter Hördaten ohne Kontolöschung. Zusätzlich wurden Wiedergabefilter, Release-Prüfungen, Kontolöschung und Android-16-Kompatibilität verbessert.
```
